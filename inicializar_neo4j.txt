# Neo4j - Jotun's Lair

## 1. Cargar la base de datos

Carga el archivo `neo4j.dump` desde la carpeta `import/` dentro de la base de datos `neo4j`.


docker run -it --rm \
  --volume="$PWD/data:/data" \
  --volume="$PWD/import:/backups" \
  neo4j:5.25 \
  neo4j-admin database load neo4j --from-path=/backups --overwrite-destination=true --verbose


## 2. Arrancar Neo4j

Arranca Neo4j con la base cargada, los plugins APOC y Graph Data Science, y expone la interfaz web y Bolt.


docker run --rm \
  --name neo4j-jotuns \
  --volume="$PWD/data:/data" \
  --volume="$PWD/plugins:/plugins" \
  --publish=7474:7474 \
  --publish=7687:7687 \
  --env NEO4J_AUTH=neo4j/password \
  --env NEO4J_PLUGINS='["apoc","graph-data-science"]' \
  neo4j:5.25


## 3. Estructura de carpetas

neo4j/
├── data/
├── import/
│   └── neo4j.dump
├── plugins/
└── README.md


* `data/`: guarda los datos reales de Neo4j después de cargar el dump.
* `import/`: contiene el archivo `neo4j.dump` que se carga inicialmente.
* `plugins/`: guarda los plugins instalados, como APOC y Graph Data Science.
* `README.md`: instrucciones básicas para cargar y arrancar Neo4j.
